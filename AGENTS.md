# Commit, pull request, and release attribution

- Never add the assistant or an automation tool as a commit author or co-author.
- Never add co-authorship or tool attribution trailers to commit messages.
- Never mention the use of ChatGPT, Codex, Anthropic, other language models, or AI automation tools in commit messages, pull request titles or bodies, release notes, or other published project materials.
- Commit messages must end with their last content line, without attribution trailers.
- This rule applies to all future work in this repository.
